# Консольный калькулятор с DLL-плагинами (Windows, C++17)

## Возможности
- `+`, `-`, `*`, `/`, `^`, скобки и унарные знаки.
- Функции из DLL: `sin(x)` (угол в градусах), `ln(x)`, `sqrt(x)`.
- Загрузка DLL из `./plugins` во время запуска.
- Имя функции берётся из метаданных плагина, а не из имени DLL.
- Ошибки выражений и ошибки функций выводятся в консоль; один неудачный ввод не завершает программу.
